# Python backend & automation

Работаю с Python, Django/DRF, REST API, PostgreSQL/SQL и обработкой CSV/Excel.

Интересуют конкретные backend-задачи: исправление ошибок, интеграции, небольшие скрипты и автоматизация повторяющейся работы с данными.

В работе уточняю ожидаемый результат, согласовываю объём и проверяю решение на воспроизводимых примерах. Использую ИИ-инструменты с проверкой кода.

В портфолио — личные и демонстрационные проекты. Демо используют синтетические данные и не выдаются за коммерческие внедрения.

Работаю удалённо из России. Возможность сотрудничества, способ оплаты, цену и сроки обсуждаем до начала задачи.

## Проверяемые примеры

[Python automation demos](https://github.com/kans-on/python-automation-demos): проверка CSV с построчным аудитом и импорт REST API в SQLite без дублей при повторном запуске. В репозитории есть исходники, синтетические примеры и 10 тестов.
